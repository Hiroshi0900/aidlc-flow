## Way of Working

- プロジェクトの AGENTS.md または CLAUDE.md に、より厳しい指示がある場合はそちらを優先する。
- 実装タスクは検査とコミットまでを完了条件とする。
- エージェントの完了報告だけを証拠にせず、親が Git 差分、commit SHA、検査出力を確認する。
- push、PR作成、deploy は、その操作に対する人間の明示的指示がある場合だけ行う。

## Verification

- 完了を主張する直前に、プロジェクトが定める完全な検査を新規実行する。
- `--no-verify`、検査の skip 化、閾値引き下げ、失敗無視で検査を迂回しない。
- 検査環境自体が壊れている場合は、迂回せず停止して人間へ報告する。
